# Notebooks

Follow this learning path:

1. Start in `01_introduction/` through `10_ensembles_unsupervised/` when following a lecture. The directories preserve course order; `../LECTURE_COVERAGE.md` gives the concept and practice outcome for every session.
2. Use `case_studies/` after the relevant lecture to apply a concept to a documented real or explicitly synthetic dataset.
3. Consult `solutions/` only after attempting its corresponding case study.

Lecture notebooks explain the ideas step by step. Case-study notebooks leave space for you to complete the analysis and state a decision, limitation, and guardrail. Start JupyterLab from the course folder so notebooks can find the required data.
