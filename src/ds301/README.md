# `ds301` package

This package contains the small reusable helpers used by the course notebooks:

- `contracts.py` — Pydantic validation models for dataset definitions and locally written provenance metadata.
- `data_catalog.py` — documented dataset registry and download loaders.
- `paths.py` — repository-safe paths for notebooks run from nested directories.
- `reporting.py` — simple audit-table and output helpers.

You do not need to edit this package to complete the notebooks. It keeps data locations and validation consistent while you focus on the analysis.
