# A4: Regression and ML evaluation

Build a leakage-safe regression study.  Compare a baseline, an MSE-based model, and one regularized or robust alternative.  Include a loss comparison, residual plot, validation split rule, MAE and RMSE.  Explain one limitation of coefficient interpretation.

The core question is not which model has the smallest number.  Explain whether the difference is large enough and stable enough to matter for the stated decision.
