# Assignments for Lectures 1–10

Each assignment asks for a notebook and a short decision memo.  Submit reproducible code, outputs, assumptions, and limitations.  Do not state a causal or operational conclusion unless the design supports it.

| Assignment | Supports lectures | Deliverable |
| --- | --- | --- |
| A1: Evidence and problem framing | 1–2 | Decision canvas and 500-word memo |
| A2: Data lifecycle and source audit | 3–5 | Data dictionary, quality checks, and project artefact map |
| A3: Forecast evidence | 6 | Chronological forecast notebook and capacity recommendation |
| A4: Regression and ML evaluation | 7–8 | Loss comparison, diagnostic plots, and validation protocol |
| A5: Classification and unsupervised evidence | 9–10 | Cost-aware classification report and cluster-validation note |
